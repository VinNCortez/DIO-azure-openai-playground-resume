# Resumo
## 🧠 Gerar textos e conversar com IA
Criar respostas automáticas, resumos, traduções, explicações e muito mais.

Simular chats com assistentes personalizados.

Ajustar o comportamento do modelo com instruções no sistema (como tom, estilo, etc.).

## ⚙️ Customizar a geração
Controlar temperatura, máximo de tokens, frequência de repetição, etc.

Definir o contexto e os exemplos de prompt-resposta para afinar o resultado.

Usar Assistants API e System Messages para orientar o modelo.

## 📝 Criar modelos personalizados (com Fine-tuning)
Carregar conjuntos de dados e treinar versões customizadas do modelo para tarefas específicas (como atendimento, jurídico, saúde, etc.).

## 🧪 Testar prompts com variantes
Comparar diferentes instruções e ver como o modelo responde.

Analisar o impacto de mudanças sutis no prompt.

## 💻 Gerar e interpretar código (com Codex)
Pedir para o modelo escrever trechos de código em várias linguagens (Python, JavaScript, C#, etc.).

Explicar trechos de código, encontrar bugs ou sugerir melhorias.

## 🔗 Integrar com APIs
Gerar exemplos de chamadas de API (como JSON ou cURL).

Simular aplicações que conversam com o modelo por meio da API do Azure.

## 📚 Salvar e compartilhar
Salvar prompts e configurações para reutilização futura.

Compartilhar sessões com a equipe para colaboração.
